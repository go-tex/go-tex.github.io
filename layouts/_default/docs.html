How to read this

go-tex is a pure-Go (CGO_ENABLED=0) re-implementation of TeX that loads and runs the genuine LaTeX classes and packages as real TeX macros. This page lists the supported surface as it actually stands in the source, and names what is still missing — the aim is that nothing goes unlisted. Statuses:

Fullfaithful, gated by an oracle Partialreal support, documented limits Stubcontent preserved, effect approximated or dropped Opt-inbehind an env flag, off by default

Document classes

The standard base classes are the genuine embedded LaTeX .cls files, run for real. Any other resolvable class loads tolerantly.

ClassStatusNotes
article · report · bookFullReal embedded .cls (LPPL, verbatim) with the size option files — numbered title, dotted \tableofcontents, numbered sections/chapters, figure/table captions, lists, math. Passes the conformance and fidelity gates. Runs identically in js/wasm.
amsartPartialReal embedded class by default; title, sections and theorem heads typeset. GOTEX_AMSART=0 forces the older emulation.
beamerPartialRuns the real beamer.cls when resolvable (measured rendering on 99.9% of 10,025 talks); otherwise a built-in emulation — one page per frame, static overlays, themes gobbled. GOTEX_BEAMER=0 forces emulation.
revtex4 / 4-1 / 4-2PartialTitle-block emulation preserving author/affiliation content. The two-column reprint layout is set by default (GOTEX_TWOCOLUMN=0 turns it off); the superscript-address layout is not reproduced.
acmartPartialRuns an amsart-shaped path with metadata stubs; content is clean, render is single-column, geometry approximated.
IEEEtran, elsarticle, aastexStubGeometry floor plus an article-shaped fallback; class-specific front-matter macros are dropped.
letter, proc, slides, minimalStubBuilt-in emulation.
any other .clsBest-effortIf resolvable (document dir, TEXINPUTS/GOTEX_TEXMF, or host resolver) it is loaded and run as real TeX; unknown commands are skipped.

Packages

Distribution-heavy packages are emulated natively; anything else resolvable runs from disk as real TeX macros, with the full LaTeX2e option mechanism (\DeclareOption, \ProcessOptions, \PassOptionsToPackage, hooks, \IfFileExists, …).

The TeX engine

A faithful re-implementation — ~306 primitives, held byte-for-byte against real TeX by a conformance ratchet.

LayerCoverage
Tokenizer (mouth)Full category-code table, comments, control words/symbols.
Macros\def (undelimited, delimited, grouped params, with backtracking), \edef/\gdef/\xdef, \let, \global, \newcommand(*)/\renewcommand/\providecommand, \newenvironment.
Expansion (gullet)\expandafter, \csname/\endcsname, \noexpand, \string, \the, \number, \romannumeral, \meaning, \uppercase/\lowercase.
Conditionals\if, \ifnum, \ifx, \ifcat, \ifodd, \ifcase, \iftrue/\iffalse, with \else/\or/\fi and nesting.
Registers & arithmetic\count, \dimen, \skip, \toks/\newtoks, \advance, \multiply, \divide, \chardef, \mathchardef, \catcode.
e-TeX\numexpr/\dimexpr (exact 64-bit), e-TeX \if extensions, \protected, \unexpanded, \detokenize — the default under LaTeX for two decades.
Boxes & glue (stomach)\hbox/\vbox/\vtop with to/spread, \kern, \hskip/\vskip + fil glue, \hrule/\vrule, \penalty, box registers, \wd/\ht/\dp — all in scaled points, TeX-exact.

Math

Math mode is delegated whole to go-tex/math: $…$ and $$…$$ source is handed to the library, which returns a self-contained SVG rendered via the OpenType MATH table (STIX Two Math). Supported: fractions, radicals, matrices, big operators with limits, stretchy delimiters, scripts and primes, ~200 named symbols, and the \mathbb/\mathcal/\mathfrak alphabets. Multi-line display environments (align/gather/multline/eqnarray/flalign) are assembled at the box level, each &-cell rendered and columns width-shared for alignment, with per-line numbering and \tag/\eqref.

A formula the library cannot parse drops that one equation (tallied in diagnostics). Common triggers: user-defined math macros, alignment inside a bare matrix environment, and \SI/\num used inside math.

Fonts & output

ConcernSupport
FontsOpenType via go-opentype — measuring, kerning, ligatures, CFF/TrueType outlines. A built-in default font so it runs with zero assets; the CLI binds -font/-boldfont/-italicfont/-monofont/-sansfont (.ttf/.otf) to \rm/\bf/\it/\tt/\sf. Type1 and the XeTeX/LuaTeX Unicode engines are not supported.
PDFVia go-pdfkit, with embedded subset fonts, a selectable text layer over the glyph outlines, and clickable link annotations — external /Link URIs and in-document /GoTo named destinations.
SVGSelf-contained pages, glyphs as <path> outlines, carrying a source map for click-to-line and live <a href> links. Multi-page output is written as name-N.svg.

FormatBehaviour
PNG, JPEG (and GIF)Full — decoded and embedded verbatim (PDF XObject / SVG data-URI); reads pHYs/JFIF DPI.
SVGPartial — embedded verbatim in the SVG driver; drawn as native vector paths in the PDF driver (a subset of path/rect/circle with translate/scale).

EPSPlaceholder — not decoded.

Lenient mode & CLI flags

Strict mode aborts on the first gap, as real TeX does. Lenient mode (gotex -lenient) turns gaps into best-effort no-ops for a preview: an undefined command is skipped along with its likely [opt]{arg} block; an unloadable figure becomes a framed placeholder; an unknown math macro drops that equation; a missing \input/\bibliography/\font file is ignored. Every skipped construct is tallied.

-report-skipped prints (frequency-sorted) the skipped commands, dropped equations, undefined environments and silent-swallow alarms after a run. -offline never fetches a support tree — embedded set, local cache and TEXINPUTS/GOTEX_TEXMF only. -format pdf|svg, -size, -margin, -o/-outdir. A runaway-expansion guard bounds macro expansion so no file can hang. Lenient mode is a preview aid, not a fidelity claim.

Environment flags

Float placement and two columns are on by default and are turned off with =0; the rest are opt-in and off until set.

FlagEffect
GOTEX_FLOATS=0On by default. Turns off real single-column float placement (top/bottom/float-page) and restores the inline path, where floats typeset where written and figure-heavy documents under-paginate. The default also evaluates one-column \linewidth/\textwidth-relative figure widths as real dimensions.
GOTEX_TWOCOLUMN=0On by default. Turns off the two-column output routine for the classes that set two columns themselves (revtex reprint, acmart sigconf/sigplan, IEEEtran). article/report/book [twocolumn] are live either way.
GOTEX_BEAMER=0 · GOTEX_AMSART=0Force the built-in emulation instead of the real class.
GOTEX_PDFRENDEROpt-in. Rasterise a PDF figure to real pixels (via the pure-Go pdfrender module) instead of a framed placeholder, so \includegraphics{fig.pdf} renders at its true height.
GOTEX_PGFOpt-in. Load the real pgf/TikZ sources (basic pictures render; heavy libraries such as pgfplots and matrix are incomplete).
GOTEX_PDFASPECTOpt-in. Size un-rasterizable PDF placeholders to their true aspect ratio.

Known gaps — not yet supported

Named honestly, so nothing goes unlisted. These are the next targets, not hidden limitations.

  • TikZ / pgf / pgfplots drawing — pictures are gobbled to a placeholder by default. Under GOTEX_PGF a basic tikzpicture (lines, rectangles, circles, fills, node text, arrows, béziers, shades) renders to real vector paths; heavy libraries — pgfplots axes, \matrix, mindmaps — and tikzcd/algorithm2e still drop. (The pgf sources are host-supplied, not embedded, so this path is never on by default.)
  • Float geometry — real placement (top/bottom/float-page) is now the default, but a figure's true size still does not pay for itself: giving un-rasterisable figures their real aspect ratio leaves the total page error unchanged, improving only the systematic bias. The page builder also has no insertions and no user \output, which is what real float and footnote placement is built on.
  • Two-column completeness — the classes that set two columns themselves (revtex reprint, acmart sigconf/sigplan, IEEEtran) now do so by default, bundled class or not. Full-width figure*/table* spanning bands remain the rough edge.
  • PDF figures (opt-in) & EPS — a PDF figure rasterises under GOTEX_PDFRENDER but is a framed placeholder by default; EPS is not decoded at all.
  • biblatex — unsupported; only BibTeX \bibliography with a plain-ish (non-.bst) style.
  • Tables — longtable, tabular* and xtabular drop (paragraph columns p/m/b and \cline are supported).
  • Assorted environments — tcolorbox, adjustbox/adjustwidth, widetext, landscape, varwidth, paralist compact lists, and unregistered theorem styles are dropped in lenient mode.
  • Page builder internals — no insertions, no \topskip, no user \output routine.
  • Unicode engines & encodings — no XeTeX/LuaTeX path; fontspec, inputenc/fontenc, babel and Type1 fonts are stubbed or unsupported.
  • The TRIP test — not yet passed.
