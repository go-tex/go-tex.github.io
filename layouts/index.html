Pure-Go TeX that runs the real LaTeX classes.
In Go and in the browser, no TeXLive.

go-tex is a pure-Go (CGO_ENABLED=0) TeX effort. Its engine is a faithful re-implementation of TeX, and on top of it it loads and runs the genuine LaTeX classes: \documentclass{article}, {report} and {book} execute the real, embedded .cls files (LPPL, verbatim) — not an emulation. They also run in the browser through js/wasm, with no server.

Why go-tex

Genuine LaTeX classes, in pure Go.

The engine is a faithful re-implementation of TeX — the category-code mouth and gullet, a scaled-point stomach with Knuth–Plass line breaking and a cost-based page builder, \halign tables, math, OpenType fonts, and PDF/SVG output. The class files are embedded and the resolver needs no filesystem, so the real classes also run in the browser — genuine LaTeX class rendering client-side, with no TeXLive and no server.

Scope

Real-LaTeX fidelity, not a claim of TeXLive parity.

The engine loads and runs the standard base classes — article, report, book and amsart as real embedded files — and any resolvable .cls/.sty runs as real TeX macros. Heavy drawing (tikz/pgf) is gated and still in bring-up, biblatex is partly supported, PDF figures need the pdfrender module, and floats typeset inline unless placement is enabled. Every supported feature — and every remaining gap — is listed in the capability reference.
